# `scripts/` map

Operator and local-verification entrypoints for versioning, signed release publication, licensed
voice-evaluation asset acquisition, deterministic capacity-fixture generation, and
fail-closed image configuration selection.
None of these scripts runs in the enclave or in a Kioku client.

| Path | Responsibility |
|---|---|
| `agent-verify.sh` | Space-guarded local verification with quick, focused, and full modes; uses locked Cargo commands and an optional bounded local `sccache`. |
| `adr0022_launch_witness.wav` / `adr0022_launch_witness.json` / `test_adr0022_launch_witness.py` | Exact, non-private 16-kHz mono PCM speech asset and bounded manifest used only by the sealed fresh-production launch owner. The test pins its bytes/container/format and normalized expected phrase so production proof must exercise ordinary capture, transcript, search, export, and deletion rather than a database fixture or storage-only substitute. |
| `disable_github_actions.py` | One-time, typed-confirmation cutover that audits by default and can disable hosted Actions in both Kioku repositories while removing branch status gates that would wait forever for deleted workflows. GitHub PRs, signed tags, and release hosting remain available. |
| `test_disable_github_actions.py` | Hermetic contracts proving the default cutover mode is read-only and mutation requires the exact typed confirmation. |
| `local_image_pipeline.py` | Fail-closed staged local replacement for the hosted enclave verification/image job. It snapshots an external user-owned mode-0600 allowlisted `KEY=VALUE` configuration once, rejects ambient Git object/repository overrides plus repository replacement refs/grafts, and runs every source/archive query with replacement resolution disabled. It probes bounded free space and the exact named BuildKit worker (never the default daemon), verifies the selected native Linux/amd64 endpoint/identity/transport before and after build, freezes/rechecks an immutable Git archive, gives each transported file a deterministic content-derived mtime so same-size changes cannot reuse stale remote bytes, and binds explicit committed Cargo/source subset hashes into the BuildKit dependency/binary cache keys. It emits an exact OCI archive without daemon loading, requires the SBOM package version to match the signed source, scans before short-lived push-only authentication, quarantines and rehashes the scanned bytes, and promotes only those exact bytes. Stable tool/model/dependency/config layers, BuildKit-secret final assembly, content-addressed receipts, crash-safe `--resume`, schema-1 evidence, and generic schema-9 metadata remain intact; the two fixed fresh tags instead emit exact ordered schema-10 metadata bound to their private config commitments and role-specific source state. `preflight` is read-only; build, scan, evidence, and push stages require explicit apply. Native-builder provisioning and warm/cold benchmark proof remain outside this checked-in software contract. |
| `adr0022_fresh_release.py` / `test_adr0022_fresh_release.py` | Provider-free exact contract and adversarial tests for fixed BOOTSTRAP `v0.8.35-adr0022-fresh-bootstrap.1` (0/0/0, runtime/Genesis off) and FINAL `v0.8.35-archive-v3-wal.10` (1/1/1, active runtime/Genesis on, nonzero live commitment, exact completed-seal byte pin), with canonical fresh-generation intent, complete KMS/SA/WIF/role tuple, opaque canary receipt/admin bindings, and role/alias crossing refusal. The BOOTSTRAP source intentionally leaves the FINAL seal pin empty. |
| `assemble_image_config.sh` | BuildKit-secret consumer for the final image layer. It parses the allowlisted runtime environment as data, rejects duplicate/unknown/control-character entries, rechecks the high-impact profile/provider/archive invariants, binds the assembled bytes to `CONFIG_SHA256`, and commits the output only after final rehash; it never evaluates shell or prints values. |
| `verify_coordinator_advancement_receipt.py` | Standalone Ed25519 verifier for the detached frozen-source release interface. It accepts only a canonical signed receipt binding repository, release tag, frozen commit, and fetched `origin/main`; `release.sh --frozen-commit` still performs the local ancestor/tag/clean-tree checks. |
| `test_local_image_pipeline.py` | Hermetic fake-tool/adversarial contracts for configuration permissions/parsing and content-stable but change-sensitive snapshot transport, committed Cargo/source cache-key binding, source/SBOM version agreement, supported Buildx JSON worker probes, pinned Linux worker/disk probes, post-build identity revalidation, explicit fallback acknowledgement, exact OCI/Skopeo arguments, scan-before-auth ordering, scanned-archive replacement quarantine, dedicated service-account impersonation, content-addressed receipts/locks, output poisoning, and unsigned evidence idempotency. |
| `local_build_evidence.py` | Canonical local release-evidence creator, Ed25519 detached signer, and verifier. It records only hashes of private configuration/build inputs, including exact schema-9 or fixed-role schema-10 release metadata bytes, and requires a current-user-owned, non-symlinked exact-mode-0600 private key plus an external pinned public-key SHA-256 trust anchor. |
| `bootstrap_local_operator_config.py` | One-time, value-redacted cutover helper that reads the immutable deployed production image through a private temporary registry credential, maps and validates its embedded reviewed configuration, and creates a new external mode-0600 local operator file without printing values. |
| `verify_local_evidence_bundle.py` | Executable `KIOKU_ENCLAVE_EVIDENCE_VERIFY`-suitable verifier for a complete local evidence directory. It rejects Git replacement refs/grafts and ambient Git overrides, verifies the pinned Ed25519 signature and exact metadata/SBOM/scan/config/source/digest bindings before emitting the validated JSON bundle; for schema 10 it parses the same already-hashed private config bytes and derives/cross-binds the fresh buckets plus sole canary receipt SHA/UUID without provider reads, while schema 9 retains legacy bucket defaults. It has no cloud side effects. |
| `release_train_enclave.py` | ADR-0033 enclave prepare/publish/verify adapter and read-only Artifact Registry/GitHub immutable-release state provider. It executes the existing fast pipeline/evidence tools from the coordinator's frozen detached source, rejects Git object substitution, binds native-builder transport and exact artifact/config/source/digest-URI coordinates, captures and verifies one exact annotated-tag object, publishes only an immutable release-asset byte snapshot, and verifies the remote tag object plus peeled commit. It emits strict coordinator JSON with exact state-home artifact files, rejects drift, forbids prepare credentials, and leaves Terraform/VM deployment outside this lane. |
| `test_release_train_enclave.py` | Hermetic adapter contracts for strict stdout, frozen-coordinate and exact-confirmation rejection, state-home artifact-file binding, destination allowlisting, prepare/later credential separation, real schema-10 bundle invocation, tag alias/object/peel checks, Git substitution refusal, SSH signer matching, and immutable asset snapshots. |
| `test_coordinator_advancement_receipt.py` | Hermetic contracts for the standalone signed frozen-source advancement receipt verifier used when `origin/main` advances after plan creation. |
| `test_local_build_evidence.py` | Isolated OpenSSL contracts for canonical evidence and private-key permissions, schema-9/schema-10 consumer/config compatibility and Git-substitution refusal, plus a fake GitHub/GCP apply-shaped release-publication test that mutates original evidence after snapshot with no network access. |
| `check_build_disk_space.py` | Refuses heavyweight local verification when the selected filesystem is below a configurable free-space floor (15 GiB by default). |
| `rust_build_lock.py` | Crash-safe, per-worktree kernel lock shared by local verification and artifact retirement so wrapper-controlled builds cannot overlap retirement. |
| `retire_rust_worktree_artifacts.py` | Dry-run-first retirement of only the exact `target/` directory in a clean, linked worktree whose exact GitHub PR head is merged; coordinates with the wrapper lock plus defensive process/Cargo-profile checks and quarantines the exact directory before deletion. Raw Cargo must not race it. |
| `test_agent_verify.py` | Fast mocked command contracts for verification modes, argument forwarding, the shared disk guard, and bounded optional `sccache`. |
| `test_rust_build_lifecycle.py` | Isolated temporary-repository contracts for disk checks and fail-closed worktree artifact retirement. |
| `test_wal_idempotency_gate.py` | Structural ADR-0022 guard that tokenizes Rust comments/literals/test items and pins all production Store mutation/save expressions, every Store factory-definition/call/literal construction site, every persistence-policy selector/reference (including the dedicated staged WAL owner), and all worker spawns by exact owner/expression digests and allowlists. It audits stable/refactor/disabled classifications plus cross-helper dependencies, self-tests qualified-call/new-factory/conditional-main evasions, and proves the heterogeneous WAL actor, parity-certified launcher, and create/get-only publisher remain private. Active email, push, and webhook claim/exact-settlement child files are inspected directly for their sealed registrations, bounded ledgers, preconditions, and absence of Store/Control/provider/runtime escape. It also pins the advisory-owner/Phase-2 family as **deleted rather than dormant**: the module file and directory must not exist, no Rust source may name `archive_v3_advisory_owner::` or `full_reviewed_mutation_set_commitment`, and the bare-name form stays legal only so the retained control-store advisory DDL and its release-absence probe still compile. |
| `test_phase3_architecture_gate.py` | Structural ADR-0022 Phase 3 guard built on the shared self-tested Rust sanitizer and bracket-aware cfg(test) stripper from `test_wal_idempotency_gate.py`: proves `RootAdvance::new` stays test-only with no production caller, the extent VFS carries no witness surface and refuses non-main file classes with no parent-file or `std::env` I/O, the commit-protocol stage enum and full-tuple CAS shape are pinned with witness stages enterable only through sealed tokens, Phase 3 files hold no backend delete/enumerate authority, Phase 3 entry symbols stay unwired outside their modules with `main.rs` declaration-only, and the WAL/vector/shadow files keep their honest fail-closed shapes; includes negative-control self-tests. |
| `bump_version.sh` | Refuses main/detached HEAD, updates the Cargo manifest and exact root lockfile package entry without compiling, validates them with locked metadata, and stages the complete release change without committing or pushing. |
| `fetch_voice_eval_assets.sh` | Downloads licensed evaluation inputs and records hashes outside Git. |
| `check_voice_release_gate.py` | Classifies a release as exact owner-only/no-claim or invokes the Rust checker for a complete real-corpus trio. |
| `test_check_voice_release_gate.py` | Fail-closed contract tests for owner-only and validated-real-corpus classifications. |
| `release.sh` | Rejects ambient Git repository/object/config overrides plus replacement refs/grafts, captures one trusted signed annotated-tag object with an exact embedded name and peeled commit, and verifies externally pinned Ed25519 evidence bound to its exact source/config/schema-9-or-10 release metadata/image digest/SBOM/scan inputs. It snapshots all five evidence assets before verification and reuses only those read-only bytes for upload/resume comparison. Dry-runs by default; with `--apply` it validates the registry digest, pushes the captured tag object ID, reads back the remote object and peel before and after immutable GitHub Release publication, and never re-resolves the mutable tag name. BOOTSTRAP and FINAL each have one fixed tag and may be published here, but `--roll` refuses both so no fresh release can enter the legacy rollout path; active generic archive-v3 rolls retain their canonical tag plus exact confirmation. Generic rollout rejects any checkout that does not match the reviewed clean deployment commit plus exact Terraform-root source seal before even refreshing origin; it recomputes the identical seal immediately before rollout, invokes only the pinned tracked `scripts/local-operations.sh`, passes the exact once-read config snapshot, and passes the seal for post-lock deployment revalidation before GCP authority or mutation. |
| `repromote_signed_image.py` | Narrow registry-floor recovery owner: verifies the external Ed25519-signed immutable release bundle, exact production configuration, and sole content-addressed build receipt, then reuses the pipeline's descriptor-sealed OCI quarantine and push-only credential boundary to re-upload exactly the retained signed digest. It never rebuilds, rescans, resigns, or edits the immutable GitHub release; dry-run is provider-free and apply requires the full tag+digest confirmation. |
| `test_repromote_signed_image.py` | Hermetic contracts for dry-run no-spend, exact artifact/digest binding, quarantined push reuse, registry readback, and pre-push refusal of manifest drift. |
| `verify_push_runtime_topology.py` / `test_verify_push_runtime_topology.py` | Fail-closed APNs singleton deployment-source seal and hermetic adversarial tests: disables Git replacement-object resolution and rejects every `refs/replace` entry, pins the reviewed deployment HEAD plus the complete sorted `infra/*.tf`/`*.tf.json` inventory and length-framed digest, rejects dirty/wrong/symlinked/unexpected source, binds the exact tracked executable blob, and makes any inline-comment, template, module, path-alias, executable substitution, or other topology change require a reviewed pin update. |
| `archive_witness_probe_config.py` | Sole strict parser for checked-in `config/archive-witness-probe.json`; forces evaluation/main probe state off and permits `probe-v1` only for exact `vX.Y.Z-witness-probe.N` prerelease tags. |
| `test_archive_witness_probe_config.py` | Adversarial exact-schema, namespace, evaluation, main, and tag-eligibility contracts for the shared probe parser. |
| `archive_v3_shadow_runtime_config.py` | Sole strict schema-2 parser/selector for checked-in `config/archive-v3-shadow-runtime.json`; validates exact all-empty off or the complete canonical single-archive WAL claim, forces evaluation and `main` pretag off, and permits active only for an exact `vX.Y.Z-archive-v3-wal.N` production tag with no operator/environment/dispatch override. |
| `validate_archive_v3_shadow_runtime_environment.sh` | Independent direct-Docker-build validator with the same off/active bucket, canonical-u64, Firestore-name, and archive-binding-commitment grammar as the checked Python/Rust configuration path. |
| `test_archive_v3_shadow_runtime_config.py` | Adversarial ordered-schema, duplicate/type/control/size, Rust-matched provider grammar, nonzero commitment, off/complete, canonical tag-selection, and direct-Docker-validator parity contracts. |
| `verify_release_metadata.py` | Strict schema-9/schema-10 validator for locally signed release metadata. Generic releases retain exact schema 9. Schema 10 is reserved for the two fixed fresh tags and binds canonical field order, exact source/tag/image/buckets, fresh generation/KMS/SA/WIF/roles, opaque canary receipt/admin commitments, positive signup, plus role-specific BOOTSTRAP 0/0/0 off/off or FINAL 1/1/1 active/on state; duplicates, booleans-as-integers, schema 7/8, aliases, and every tuple drift remain ineligible. |
| `test_release.py` | Static local-release contracts for the absence of hosted workflow dependencies, ordering of evidence/tag/digest/SBOM checks before `--apply` publication, and pre-authority plus immediate pre-roll verification of active archive-v3 WAL and exact deployment-source seals. |
| `test_verify_release_metadata.py` | Adversarial contract tests for missing/different media claims, substituted source/image-digest fields, schema-7/8 rejection, exact off/active eight-element runtime claims, and schema-10 duplicate/order/type/tag/generation/KMS/WIF/role/canary/schema tuple drift. |
| `test_release_race.sh` | Compatibility executable entrypoint for the isolated local evidence/fake GitHub release-publication contracts. |
| `select_build_configuration.py` | Atomically selects and validates one complete production or evaluation image profile, including reviewed `shadow|enforce` billing and the shared checked-in probe profile without repository-variable/dispatch witness inputs or cross-profile fallback. |
| `test_select_build_configuration.py` | Contract tests for profile isolation, exact runtime tag selection/no overrides, the local pipeline's reviewed Docker arguments, generic schema-9 wiring, fixed schema-10 BOOTSTRAP selection, FINAL alias refusal, and the current BOOTSTRAP tree's deliberate FINAL ineligibility. |
| `generate_capacity_fixture.py` | Validates ADR-0022's versioned v1/v2 capacity manifests and streams content-free synthetic distributions into ignored/out-of-tree output; an explicit option can create the declared 32-GiB logical sparse shape without writing 32 GiB of blocks. |
| `test_generate_capacity_fixture.py` | Validates v1 480/960/1,200-hour and v2 12-month 40/80/100-hour distributions plus bounded deterministic generation without creating the 32-GiB shape. |
| `run_archive_capacity_harness.py` | Offline ADR-0022 content-free SQLite smoke harness. It binds resumable output to an exclusive receipt, verifies exact counts/integrity/export digest, and permanently refuses full/release-evidence claims. |
| `test_run_archive_capacity_harness.py` | Contract tests for smoke-only false evidence, exact integrity/counts, receipt-bound resume, output safety, argument validation, and percentile behavior. |
| `run_archive_capacity_gate.py` | Explicit, long-running local production-shaped capacity gate for the v2 12-month 40/80/100-hour fixtures. It streams numeric rows plus bounded zero-filled payload/vector-shape BLOBs, verifies local SQLite DB/WAL/checkpoint behavior and 32-GiB page geometry, and probes sparse near-ceiling extents without materializing a giant snapshot. |
| `test_run_archive_capacity_gate.py` | Fast contracts for the no-I/O plan, mandatory operator acknowledgements, component-by-component symlink rejection, no-follow report writes, profile-derived free-space geometry, and mocked sparse-extent geometry; it does not execute the long-running SQLite gate or create large files. |
| `verify_archive_v3_capacity_report.py` | Offline restricted-JCS verifier for the inactive ADR-0022 contract; enforces the exact workload-by-case/metric/result matrix, pinned environment, paired live-size write traces and derived growth, transport/ANN/lifecycle/deletion semantics, DER-validates P-256, executes a private copy of an absolute-path, hash-pinned verifier binary with a restricted environment, lists untrusted-wrapper blockers, and never grants authority. |
| `test_verify_archive_v3_capacity_report.py` | Adversarial tests for P-256 key type/curve, exact cross-products and environments, tiny/substituted workloads, strict boundaries, transport/write/root/witness/ANN/deletion, freshness, malformed wrappers, bounded regular inputs, replay, and signatures. |
