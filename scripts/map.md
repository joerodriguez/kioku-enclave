# `scripts/` map

Operator and local-verification entrypoints for versioning, signed release publication, licensed
voice-evaluation asset acquisition, deterministic capacity-fixture generation, and
fail-closed image configuration selection.
None of these scripts runs in the enclave or in a Kioku client.

| Path | Responsibility |
|---|---|
| `agent-verify.sh` | Space-guarded local verification with quick, focused, and full modes; uses locked Cargo commands and an optional bounded local `sccache`. |
| `disable_github_actions.py` | One-time, typed-confirmation cutover that audits by default and can disable hosted Actions in both Kioku repositories while removing branch status gates that would wait forever for deleted workflows. GitHub PRs, signed tags, and release hosting remain available. |
| `test_disable_github_actions.py` | Hermetic contracts proving the default cutover mode is read-only and mutation requires the exact typed confirmation. |
| `local_image_pipeline.py` | Fail-closed staged local replacement for the hosted enclave verification/image job. It snapshots an external user-owned mode-0600 allowlisted `KEY=VALUE` configuration once, probes bounded free space and the exact named BuildKit worker (never the default daemon), verifies the selected native Linux/amd64 endpoint/identity/transport before and after build, freezes/rechecks an immutable Git archive, gives each transported file a deterministic content-derived mtime so same-size changes cannot reuse stale remote bytes, and binds explicit committed Cargo/source subset hashes into the BuildKit dependency/binary cache keys. It emits an exact OCI archive without daemon loading, requires the SBOM package version to match the signed source, scans before short-lived push-only authentication, quarantines and rehashes the scanned bytes, and promotes only those exact bytes. Stable tool/model/dependency/config layers, BuildKit-secret final assembly, content-addressed receipts, crash-safe `--resume`, schema-1 evidence, and schema-9 metadata remain intact. `preflight` is read-only; build, scan, evidence, and push stages require explicit apply. Native-builder provisioning and warm/cold benchmark proof remain outside this checked-in software contract. |
| `assemble_image_config.sh` | BuildKit-secret consumer for the final image layer. It parses the allowlisted runtime environment as data, rejects duplicate/unknown/control-character entries, rechecks the high-impact profile/provider/archive invariants, binds the assembled bytes to `CONFIG_SHA256`, and commits the output only after final rehash; it never evaluates shell or prints values. |
| `verify_coordinator_advancement_receipt.py` | Standalone Ed25519 verifier for the detached frozen-source release interface. It accepts only a canonical signed receipt binding repository, release tag, frozen commit, and fetched `origin/main`; `release.sh --frozen-commit` still performs the local ancestor/tag/clean-tree checks. |
| `test_local_image_pipeline.py` | Hermetic fake-tool/adversarial contracts for configuration permissions/parsing and content-stable but change-sensitive snapshot transport, committed Cargo/source cache-key binding, source/SBOM version agreement, supported Buildx JSON worker probes, pinned Linux worker/disk probes, post-build identity revalidation, explicit fallback acknowledgement, exact OCI/Skopeo arguments, scan-before-auth ordering, scanned-archive replacement quarantine, dedicated service-account impersonation, content-addressed receipts/locks, output poisoning, and unsigned evidence idempotency. |
| `local_build_evidence.py` | Canonical local release-evidence creator, Ed25519 detached signer, and verifier. It records only hashes of private configuration/build inputs, including exact schema-9 release metadata bytes, and requires a current-user-owned, non-symlinked exact-mode-0600 private key plus an external pinned public-key SHA-256 trust anchor. |
| `bootstrap_local_operator_config.py` | One-time, value-redacted cutover helper that reads the immutable deployed production image through a private temporary registry credential, maps and validates its embedded reviewed configuration, and creates a new external mode-0600 local operator file without printing values. |
| `verify_local_evidence_bundle.py` | Executable `KIOKU_ENCLAVE_EVIDENCE_VERIFY`-suitable verifier for a complete local evidence directory. It verifies the pinned Ed25519 signature and exact metadata/SBOM/scan/config/source/digest bindings before emitting the validated JSON bundle; it has no cloud side effects. |
| `release_train_enclave.py` | ADR-0033 enclave prepare/publish/verify adapter and read-only Artifact Registry/GitHub immutable-release state provider. It executes the existing fast pipeline/evidence tools from the coordinator's frozen detached source, binds native-builder transport and exact artifact/config/source coordinates, emits strict coordinator JSON with exact state-home artifact files, rejects drift, forbids prepare credentials, and leaves Terraform/VM deployment outside this lane. |
| `test_release_train_enclave.py` | Hermetic adapter contracts for strict stdout, frozen-coordinate and exact-confirmation rejection, state-home artifact-file binding, destination allowlisting, and prepare/later credential separation. |
| `test_coordinator_advancement_receipt.py` | Hermetic contracts for the standalone signed frozen-source advancement receipt verifier used when `origin/main` advances after plan creation. |
| `test_local_build_evidence.py` | Isolated OpenSSL contracts for canonical evidence and private-key permissions, plus a fake GitHub/GCP apply-shaped release-publication test with no network access. |
| `check_build_disk_space.py` | Refuses heavyweight local verification when the selected filesystem is below a configurable free-space floor (15 GiB by default). |
| `rust_build_lock.py` | Crash-safe, per-worktree kernel lock shared by local verification and artifact retirement so wrapper-controlled builds cannot overlap retirement. |
| `retire_rust_worktree_artifacts.py` | Dry-run-first retirement of only the exact `target/` directory in a clean, linked worktree whose exact GitHub PR head is merged; coordinates with the wrapper lock plus defensive process/Cargo-profile checks and quarantines the exact directory before deletion. Raw Cargo must not race it. |
| `test_agent_verify.py` | Fast mocked command contracts for verification modes, argument forwarding, the shared disk guard, and bounded optional `sccache`. |
| `test_rust_build_lifecycle.py` | Isolated temporary-repository contracts for disk checks and fail-closed worktree artifact retirement. |
| `test_wal_idempotency_gate.py` | Structural inactive ADR-0022 guard that tokenizes Rust comments/literals/test items and pins all production Store mutation/save expressions, every Store factory-definition/call/literal construction site, every persistence-policy selector/reference (including the dedicated staged WAL owner), and all worker spawns by exact owner/expression digests and allowlists. It audits stable/refactor/disabled classifications plus cross-helper dependencies, self-tests qualified-call/new-factory/conditional-main evasions, and proves the heterogeneous WAL actor, parity-certified launcher, and create/get-only publisher remain private and absent from main/runtime/provider activation wiring. |
| `test_phase3_architecture_gate.py` | Structural ADR-0022 Phase 3 guard built on the shared self-tested Rust sanitizer and bracket-aware cfg(test) stripper from `test_wal_idempotency_gate.py`: proves `RootAdvance::new` stays test-only with no production caller, the extent VFS carries no witness surface and refuses non-main file classes with no parent-file or `std::env` I/O, the commit-protocol stage enum and full-tuple CAS shape are pinned with witness stages enterable only through sealed tokens, Phase 3 files hold no backend delete/enumerate authority, Phase 3 entry symbols stay unwired outside their modules with `main.rs` declaration-only, and the WAL/vector/shadow files keep their honest fail-closed shapes; includes negative-control self-tests. |
| `bump_version.sh` | Refuses main/detached HEAD, updates the Cargo manifest and exact root lockfile package entry without compiling, validates them with locked metadata, and stages the complete release change without committing or pushing. |
| `fetch_voice_eval_assets.sh` | Downloads licensed evaluation inputs and records hashes outside Git. |
| `check_voice_release_gate.py` | Classifies a release as exact owner-only/no-claim or invokes the Rust checker for a complete real-corpus trio. |
| `test_check_voice_release_gate.py` | Fail-closed contract tests for owner-only and validated-real-corpus classifications. |
| `release.sh` | Verifies a pre-existing trusted signed tag and externally pinned Ed25519 local evidence bound to its exact source/config/schema-9 release metadata/image digest/SBOM/scan inputs; dry-runs by default, and with `--apply` validates the registry digest, pushes the tag, and publishes an immutable GitHub Release with the metadata as a fifth asset. Its optional deployment roll rejects the active archive-v3 WAL image profile before even refreshing origin, tag verification, cloud authentication, publication, or rollout until the downstream compatibility PR exists. |
| `archive_witness_probe_config.py` | Sole strict parser for checked-in `config/archive-witness-probe.json`; forces evaluation/main probe state off and permits `probe-v1` only for exact `vX.Y.Z-witness-probe.N` prerelease tags. |
| `test_archive_witness_probe_config.py` | Adversarial exact-schema, namespace, evaluation, main, and tag-eligibility contracts for the shared probe parser. |
| `archive_v3_shadow_runtime_config.py` | Sole strict schema-2 parser/selector for checked-in `config/archive-v3-shadow-runtime.json`; validates exact all-empty off or the complete canonical single-archive WAL claim, forces evaluation and `main` pretag off, and permits active only for an exact `vX.Y.Z-archive-v3-wal.N` production tag with no operator/environment/dispatch override. |
| `validate_archive_v3_shadow_runtime_environment.sh` | Independent direct-Docker-build validator with the same off/active bucket, canonical-u64, Firestore-name, and archive-binding-commitment grammar as the checked Python/Rust configuration path. |
| `test_archive_v3_shadow_runtime_config.py` | Adversarial ordered-schema, duplicate/type/control/size, Rust-matched provider grammar, nonzero commitment, off/complete, canonical tag-selection, and direct-Docker-validator parity contracts. |
| `verify_release_metadata.py` | Strict schema-9 validator for locally signed release metadata: binds the exact immutable GitHub release URL, source/tag/image digest, bucket topology, shared voice-gate result, exact probe claim, and complete eight-element archive-v3 runtime claim through their shared checked-in parsers; schemas 7/8 remain ineligible. |
| `test_release.py` | Static local-release contracts for the absence of hosted workflow dependencies, ordering of evidence/tag/digest/SBOM checks before `--apply` publication, and pre-authority quarantine of active archive-v3 WAL deployment rolls. |
| `test_verify_release_metadata.py` | Adversarial contract tests for missing/different media claims, substituted source/image-digest fields, schema-7/8 rejection, and exact off/active eight-element runtime claims including the archive-binding commitment. |
| `test_release_race.sh` | Compatibility executable entrypoint for the isolated local evidence/fake GitHub release-publication contracts. |
| `select_build_configuration.py` | Atomically selects and validates one complete production or evaluation image profile, including reviewed `shadow|enforce` billing and the shared checked-in probe profile without repository-variable/dispatch witness inputs or cross-profile fallback. |
| `test_select_build_configuration.py` | Contract tests for profile isolation, exact runtime tag selection/no overrides, the local pipeline's reviewed Docker arguments, and schema-9 release metadata claim wiring. |
| `generate_capacity_fixture.py` | Validates ADR-0022's versioned v1/v2 capacity manifests and streams content-free synthetic distributions into ignored/out-of-tree output; an explicit option can create the declared 32-GiB logical sparse shape without writing 32 GiB of blocks. |
| `test_generate_capacity_fixture.py` | Validates v1 480/960/1,200-hour and v2 12-month 40/80/100-hour distributions plus bounded deterministic generation without creating the 32-GiB shape. |
| `run_archive_capacity_harness.py` | Offline ADR-0022 content-free SQLite smoke harness. It binds resumable output to an exclusive receipt, verifies exact counts/integrity/export digest, and permanently refuses full/release-evidence claims. |
| `test_run_archive_capacity_harness.py` | Contract tests for smoke-only false evidence, exact integrity/counts, receipt-bound resume, output safety, argument validation, and percentile behavior. |
| `run_archive_capacity_gate.py` | Explicit, long-running local production-shaped capacity gate for the v2 12-month 40/80/100-hour fixtures. It streams numeric rows plus bounded zero-filled payload/vector-shape BLOBs, verifies local SQLite DB/WAL/checkpoint behavior and 32-GiB page geometry, and probes sparse near-ceiling extents without materializing a giant snapshot. |
| `test_run_archive_capacity_gate.py` | Fast contracts for the no-I/O plan, mandatory operator acknowledgements, component-by-component symlink rejection, no-follow report writes, profile-derived free-space geometry, and mocked sparse-extent geometry; it does not execute the long-running SQLite gate or create large files. |
| `verify_archive_v3_capacity_report.py` | Offline restricted-JCS verifier for the inactive ADR-0022 contract; enforces the exact workload-by-case/metric/result matrix, pinned environment, paired live-size write traces and derived growth, transport/ANN/lifecycle/deletion semantics, DER-validates P-256, executes a private copy of an absolute-path, hash-pinned verifier binary with a restricted environment, lists untrusted-wrapper blockers, and never grants authority. |
| `test_verify_archive_v3_capacity_report.py` | Adversarial tests for P-256 key type/curve, exact cross-products and environments, tiny/substituted workloads, strict boundaries, transport/write/root/witness/ANN/deletion, freshness, malformed wrappers, bounded regular inputs, replay, and signatures. |
| `phase1_provision_archive_resources.py` | Strictly non-mutating emitter of the ADR-0022 Phase-1 provisioning plan (`docs/adr/0022-phase1-resource-provisioning-plan.md`): numbered exact `gcloud` commands with runbook justifications for the dedicated code-pinned WIF pools/providers, archive bucket with custom create/get-only role, registry-KMS version pin verification, named non-default witness database with a conditional database-scoped custom role, and the export-only backup lane. It has no apply mode, exits nonzero naming every missing mandatory `REQUIRED_DECISION_*` flag, and offers `--emit-shell` (fail-closed `set -euo pipefail` transcript gated on the C4 approval digest) and `--plan-digest` (SHA-256 of the canonicalized plan for the signed approval artifact). |
| `test_phase1_provision_archive_resources.py` | Invariant contracts on the emitted plan: every IAM member is an image_digest-pinned `principalSet` or the one listed Firestore backup service agent; no admin/list/delete/update/setIamPolicy or predefined-role grants; named witness database never `(default)` with an exact-database condition; enforced bucket posture flags; audiences equal the pinned Rust source constants; missing decisions exit nonzero by name; and the plan digest is stable and flag-sensitive. |

The Python selector is CI/operator tooling only. The macOS and iOS clients remain pure
Swift and the enclave runtime remains Rust.
