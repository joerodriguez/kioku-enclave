# map.md — `src/cp/media_worker/wal/`

|---|---|
| `claim.rs` | **Media work claim boundary (ADR-0022 slice 10i):** the missing durable boundary every settle family downstream already anchors on. It re-runs the identical bounded eligibility query the owner enumerated with (one definition, shared by construction), re-derives the member set through the same pure planner, and requires exact equality with the carried set before writing; the identity is the resolved member set plus every observed `media_work_units` field used by the constructor and the carried total-attempt cap, never the clock. Rows whose capture stamps or predecessor fields violate the settle bounds, including job attempts already at/above that cap, are named as `Unplannable` before any reservation/provider call; a non-empty enumeration whose deterministic head fits no planner window is also named rather than collapsed into `Idle`. A structured classifier names exact durable member, duplicate-event, or stored-work-unit evidence (malformed, future, exhausted attempt count, or mismatched immutable class/version/window/token topology), while global account/constants/clock/code failures remain log-only and non-charging; the plan-wide backward-clock check precedes member timestamp attribution. Construction and transactional re-resolution share the cap; job/unit increments use checked Rust values and guarded integer SQL assignments, never raw arithmetic. `lease_until` survives only as a deterministic derived recovery deadline (`committed_at + 300s`) — never renewed, no holder id, no fencing token — because it is the sole path back for a unit abandoned mid-flight and because the sealed `result`/`audio_result` settles CAS on its exact byte value. `created_at`/`updated_at` are bound explicitly so no `strftime` DEFAULT can fire inside `apply()`. **`scan_for_claim` carries the T24 audio gate: it reads the two allocator tables' DDL and opens on the current sealed `AUTOINCREMENT` baseline, while retaining a fail-closed residual defence against a missing table or legacy pre-re-baseline plain-primary-key shape. It deliberately does not require existing `sqlite_sequence` rows, which virgin `AUTOINCREMENT` tables do not have.** No provider call, no media read, no clock, no Store, no launcher, no retry loop. |
| `quarantine.rs` | **Deterministic claim-refusal quarantine:** the bounded response to a named claim refusal. It commits every column in the complete joined claim rows plus all existing-work-unit predecessor and expected immutable-topology fields when applicable, sorts members by job id for canonical multi-row identity, transactionally rereads and re-derives all evidence before the first write, and rejects repaired/stale plans with no mutation. It covers malformed/unwindowable members, member commit order, duplicate-event topology, and malformed/future/derived-mismatched existing work units. One transaction advances attempts without overflow, parks or terminalizes jobs on the carried retry/resurrection bounds, settles an evidenced work unit, and applies one aggregate media disposition per event so duplicate jobs cannot self-invalidate. Replay is permanent and exact. It cannot create a work unit or reservation, read media, call a provider, allocate a clock/id, launch, or retry. |
| `failure.rs` | **Media work failure tail (ADR-0022 slice 10i):** one plan, one transaction, over the whole legacy tail — per-job `mark_failed` or `defer_for_budget` plus the work-unit state/error update — each write a full-tuple CAS on the carried predecessor. `attempt_limit`, `resurrection_window_seconds` and `budget_retry_seconds` are carried, never read from a code constant inside `apply()`. **In both arms the non-terminal branch writes the FUTURE retry time into `updated_at`, not the commit stamp:** `updated_at` doubles as next-attempt-at for every eligibility predicate on this lane, so binding it to `committed_at` would destroy the exponential backoff and turn a transient Vertex outage into a paid retry storm. `error_code` is part of the identity. No provider call, no clock, no Store, no launcher, no retry loop. |
