# map.md — src/cp/ (in-enclave control plane)

The control plane runs inside the enclave. All
of this runs in the one attested binary; handlers call the data-plane query/storage code
([`../search.rs`](../map.md), `../timeline.rs`, `../episodes.rs`, `../ingest.rs`) in-process
— no HTTP hop. Routes are wired in [`../main.rs`](../map.md).

| File | Role |
|---|---|
| `mod.rs` | `CpConfig` validates image-baked OAuth audiences, optional atomic Apple identifiers, allow-list, HTTPS API/browser origins, the optional exact-match Identity Platform reviewer identity, Vertex, and quotas; production JWT secrets come from the KMS-protected control store and web/Apple private credentials come from Secret Manager. `CpState` holds shared stores, verifiers, limiters, and the embedder |
| `tokens.rs` | HS256 JWTs (resource-audience access tokens plus OAuth state/consent/auth-code tokens, including signed Apple browser nonce/link target), PKCE S256, sha256-hex, opaque tokens, UUIDv4, and provider-domain-separated canonical account IDs that preserve historical Google IDs. Access verification temporarily accepts the legacy `kioku-mcp` audience during rollout |
| `control_store.rs` | Provider-neutral identity mappings, encrypted per-Apple-client refresh authorization with automatic legacy single-row migration, and identity/account deletion state in the context-bound encrypted SQLite blob `control/control.db.enc`. Each canonical user receives one persisted cryptographically random opaque archive binding, with an internal-only tombstone and cursor-shaped inventory ledger that fences future v3 work before ordinary identity removal; it has no v3 provider I/O or v3 completion state and never appears in APIs, exports, logs, or telemetry. Legacy Google-ID rebinding is a separate durable staged operation containing exact old/stable namespaces, archive binding, source generation, and content-free commitment before provider mutation. It composes Store's two-user lifecycle/admission fence with retained provider markers, bounded durable write-intent drains, and a mandatory source-generation CAS bump; supports exact SourceFreezing rebase, conditionally creates/validates stable content, purges old generations, and atomically commits the identity/binding move. Startup drains bounded pages without reauthentication. Live deletion retries actively resume SourceFreezing/StableWriting under durable intent ownership, claim both namespaces, and require `deletion_reconciled` before finalization. The same blob holds accounting, protected audio/screen/derived-text cost reservations, webhook destinations/secrets, OAuth clients/codes, refresh tokens, daily usage/Vertex ceilings, and the redacted query log; email equality never links providers. |
| `apple.rs` | Native and browser Sign in with Apple verification plus explicit native/web account linking: validates request shape, RS256 identity-token signature/issuer/platform audience/expiry/native-hashed-or-web-raw nonce/verified email, exchanges the single-use code, issues Kioku native sessions or enters the shared browser consent/code path, exposes canonical session metadata, and redirects web linking only to the fixed browser origin |
| `auth.rs` | End-user Google ID-token verifier (audiences = our OAuth client ids), exact UID/email Google Identity Platform reviewer-token verifier, and `require_auth` middleware → attaches `AuthUser`; deleting/deleted authentication remains accepted only for account DELETE retry and deletion-status polling |
| `cors.rs` | Hand-rolled CORS for the single image-baked HTTPS `WEB_ORIGIN`: answers OPTIONS preflights and stamps `Access-Control-Allow-Origin` only for that exact origin. Layered outside `require_auth` so preflights do not 401; bearer tokens still gate requests |
| `oauth.rs` | OAuth 2.1-style facade + bounded DCR: publishes `WEB_ORIGIN/app/login` as the authorization endpoint, shares validation/consent/code/rotation between Google and Apple, reserves one exact first-party web PKCE client and one fixed native client whose only variable redirect component is an explicit ephemeral port on exact `127.0.0.1/oauth/callback`, accepts the special page's short-lived exact-match reviewer token at `/oauth/reviewer`, and issues resource-bound persisted single-use authorization codes with PKCE and atomic client-bound refresh rotation at `/token`; publishes the read-only `kioku:read` scope |
| `reviewer.rs` | Idempotently seeds only the exact Google-authenticated, namespaced reviewer identity with the synthetic launch, cache-debugging, renewal-link, and French-lesson archive used by public plugin test cases |
| `screen_understanding.rs` | Deterministic ingest-time screen fallback types and validators. It has no model client or model worker; authoritative screen semantics are produced holistically by `finalizer.rs` |
| `sync.rs` | `/api/sync/batch` joins utterances to segments and validates device-scoped nested browser snapshots plus additive screenshot provenance before transactional ingest; also serves `/status`, `/api/export`, `/api/account`, and `/api/account/deletion`. The export value and the inactive ADR-0022 checker share one fixed table/order definition; the HTTP route preserves its existing JSON body and headers, while the checker streams a separately versioned digest with hard row/field/total bounds and cancellation checks instead of materializing the full export. Account deletion returns durable 200/202 `pending`/`failed_retryable`/`physical_complete` state with current provider deadlines, durably marks and safely retries interrupted attempts, keeps missing-generation, unsettled-write-intent, and compatibility-cap failures out of automatic completion, and runs a serial bounded startup/periodic reconciler with aggregate-only logs. If either side of a durable identity rebind is present, deletion actively settles a provider-writing stage, claims the operation, drains retained-marker write intents before and after purging both exact namespaces, persists `deletion_reconciled`, and only then permits identity finalization. |
| `media.rs` | Cloud Capture API v2: strict timestamp/media/browser manifest, exact byte/container verification, idempotent stream acknowledgements, per-user context-bound raw-media encryption, and ADR-0016 metadata-only Mac screen references. Raw capture holds a Store content-write lease from preflight through durable index save and moves a child lease into its owned GCS PUT, so request cancellation cannot race account deletion inventory. References are fingerprint/context checked against one earlier canonical event in the same account/device/install/session/stream, retain every timestamp/browser observation, cannot chain, and create neither media nor Gemini jobs. Owns same-name-safe people/name/fact/evidence migrations, including one-time removal of request-local Gemini speaker labels plus conservative same-work-unit reconciliation, and paginated read-only learned-people/profile/evidence/statement endpoints that never expose biometric vectors |
| `media_planner.rs` | Pure deterministic ADR-0016 planner for five-minute compatible audio windows, 90-second/12-frame storyboards, exact cross-event interval projection, audio-first class scheduling, and the three-hour capture/cost regression fixture |
| `media_worker.rs` | Durable leased Gemini work-unit worker: decrypts bounded raw objects inside the enclave, assembles adjacent audio as canonical 16-kHz WAV and canonical screens as opaque-ID storyboards, prompts with source kind and conservative within-asset speaker continuity, persists exact source offsets, and treats Gemini local speaker IDs only as work-unit-scoped grouping hints. A unique independent name/voice resolution may label unresolved same-ID sibling turns; conflicts abstain and all remaining local-ID fallbacks become `Unidentified voice`. The worker uses protected class reservations with retained retry identity and non-content actual-usage telemetry, atomically validates/projects results, stops after three attempts, and prunes retained media with bucket-local generations plus context-bound decryption and the persisted plaintext SHA-256 before marking the ledger row pruned. New rows record current-backend provenance; migrated rows without provenance authenticate each provider's own live generation, and any mismatching live object keeps cleanup retryable. Each sweep grants audio the first of at most two per-user class slots. Direct self-identification and repeated exact active-speaker frames create provenance-bound claims; roster/hint names cannot bind; every confidently attributed turn may add temporal facts |
| `voice_memory.rs` | Python-free voice memory: pure-Rust AAC/WAV decoding, 16 kHz Kaldi fbank, pinned WeSpeaker ONNX inference through tract, granular acoustic-domain matching with calibrated ambiguity margins, robust representatives, match-only/enrollment separation, encrypted samples/diagnostics, and bounded idempotent reconciliation |
| `voice_lineage.rs` | Append-only encrypted voice-profile revision and active-sample-assignment graph. It validates bounded same-space/domain/identity merge and anonymous split proposals, applies them transactionally, relabels derived observations, and supports fail-closed reversal without deleting source profiles or sample history; threshold-driven proposal acceptance remains release-corpus gated |
| `voice_quality.rs` | Versioned duration, speech-purity, energy/SNR proxy, clipping, silence, overlap, and model-flag policy plus normalized medoid/trimmed-centroid representatives and outlier rejection |
| `voice_eval.rs` | Strict schema-v2 multi-artifact source/physical-route manifest validator and JSON scorer/checker for ADR-0016 accepted-name precision, wrong-person bindings, cross-meeting links, recognition recall, denominator-visible identity/abstention metrics and diarization regression by slice, same-name collisions, fact provenance, export/delete coverage, and the hash-bound real-audio release gate |
| `voice_eval_assets.rs` | Offline, network-free licensed-corpus derivation: verifies manifest-bound artifact/label hashes, extracts exact `.tar.gz` or entry/member-bounded ZIP members in memory, accepts only mono 16-kHz PCM16, applies bounded fixed-point trim/overlap/mix recipes, permits slice-compatible cross-source tracks only from explicitly typed augmentation artifacts, and atomically emits canonical WAVs, opaque timing/augmentation labels, and a content-free hash receipt outside Git |
| `voice_eval_evidence.rs` | Strict schema-v3 real-run reducer: binds opaque timing/identity/record evidence to exact reviewed primary and independently licensed augmentation artifacts plus authorized physical owner captures, computes permutation-invariant overlap-aware diarization plus its deterministic speaker mapping, requires identity decisions to match mapped hypotheses, derives every release count, pins image/model/scorer/export/delete artifacts, and rejects hand-authored schema-v1 quality claims |
| `voice_eval_similarity.rs` | Offline ADR-0016 calibration tool: verifies an opaque private specification, exact production WeSpeaker model/media hashes, canonical duration and enrollment quality, then emits only deterministic integer pair similarities and hardest genuine/impostor bindings—never vectors or content |
| `query.rs` | MCP server `/mcp` with minimized/sanitized screenshot observation fields plus REST search, episode members, feed, authenticated lazy browser-snapshot tabs, purge, screenshot evidence, and webhook routes. New selected screenshot evidence uses the store-owned validated per-user raw-media key constructor plus the same cancellation-safe content-write lease as Cloud Capture; legacy selected evidence remains readable/deletable by its stored key. Episode members expose every canonical screen with literal observation and episode ranking independent of cloud image presence |
| `mcp_safety.rs` | MCP-only restricted-data boundary: refuses searches targeting payment-card data, health information, government identifiers, or access credentials; redacts matching incidental values recursively after response projection; strips URL query strings/fragments; and fails closed on malformed URLs or oversized strings without modifying the private archive or REST/debugger output |
| `summarizer.rs` | v2 incremental episode summarizer + internal tokio cron (replaces Cloud Scheduler). Open-episode context carries type, participants, the current summary and action items, and the recent timeline so the model extends a shared workflow instead of fragmenting it. Single-pass output includes a concrete, actionable summary, attributed minute gists, exact user-directed actions/resources (including full captured URLs), ADR-0009 substance, and ADR-0010 visual-evidence classification. Automatic sweeps process at most one window, reserve their maximum output before inference, and never launch historical classification regeneration; any future explicit maintenance path remains separately budgeted. After upsert it embeds each episode in-enclave (candle, pinned MODEL_ID → `vec_episodes`, §G.2). Live-tail cursor semantics hold short/empty tails as documented in the module |
| `finalizer.rs` | Episode finalization worker that waits for the summarizer cursor and contributing-device watermarks, then sends one bounded text/metadata request containing prioritized transcript, canonical screens, browser-tab context, and opaque URL candidates to `VERTEX_MODEL`. It validates exact screen-ID coverage and candidate-ID-only links, ranks key screens, and atomically stores the brief plus screen observations/interpretations. Background sweeps process at most one never-finalized episode; historical completed briefs are terminal unless explicitly retried. Model/validation failures back off for 10 minutes and then one hour before becoming terminal on the third attempt. First-time finalization snapshots enabled webhook destinations and email preferences into opaque outbox tables; regeneration preserves `finalized_at` and never replays deliveries |
| `delivery.rs` | Canonical `FinalizedEpisode` delivery data model and database loader shared across outbound channels |
| `email_renderer.rs` | Pure email text and HTML body renderer, HTML escaping, and link safety validation |
| `email_worker.rs` | Resend transactional email outbox worker. Re-verifies user email preference, sends notification-only or full brief emails via Resend with stable 24-hour idempotency keys, handles retries, and avoids secret or content logging |
| `webhook_worker.rs` | Signed CloudEvents outbox worker for user-configured destinations. It re-fetches each active subscription, builds content-free or explicitly content-bearing finalized-episode events, validates and pins public DNS addresses, refuses redirects, signs the exact body with Standard Webhooks headers, retries bounded transient failures, pauses invalid/gone destinations, and avoids logging endpoint paths or content |
| `vertex.rs` | Vertex Gemini client (`generateContent`) using the configured project/location/model with constrained schemas for text, bounded inline audio, and opaque-ID storyboards; every call carries one of four bounded cost operations. Usage/model/traffic metadata is preserved without content and the selected inference plaintext boundary remains documented |
| `limits.rs` | Token-bucket limiter + persistent daily ingest quotas and atomic pre-inference Vertex output-token reservations. The global ceiling is fail-closed into protected 50% audio, 25% screen, and 25% derived-text allocations; screens cannot borrow audio capacity. The full possible response remains reserved on timeouts. MCP tools use only the volatile rate limiter so read-only calls do not persist user or query state |
| `isotime.rs` | RFC3339-UTC parse/format/add (no `chrono`; musl-friendly) |

> Identity/accounting writes are low-volume, so the control store persists the whole blob
> per write (fine here, unlike user indexes — see ADR-0002). Keep this `map.md` and the
> public API documentation and downstream clients in sync when routes change.
