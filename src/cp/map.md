# map.md — src/cp/ (in-enclave control plane)

The control plane runs inside the enclave. All
of this runs in the one attested binary; handlers call the data-plane query/storage code
([`../search.rs`](../map.md), `../timeline.rs`, `../episodes.rs`, `../ingest.rs`) in-process
— no HTTP hop. Routes are wired in [`../main.rs`](../map.md).

| File | Role |
|---|---|

| `control_store.rs` | Provider-neutral identity mappings, encrypted per-Apple-client refresh authorization, per-device APNs installation registry with account rebind/token-generation fencing and deterministic cap, and identity/account deletion state in the context-bound encrypted SQLite blob `control/control.db.enc`. The same blob contains the inactive ADR-0022 bounded lifecycle anchor plus a separately versioned initial-witness protocol row enrolled atomically with each new reservation. That row binds archive/attempt, optional exact prepared witness hash/length, admitted revision, monotonic send phase, deletion fence, and a domain-separated commitment; candidate-free reservation/objects-prepared deletion is an explicit all-`None` tuple. Firestore send-start and account deletion serialize through this state: deletion distinguishes provably unstarted from started/ambiguous dispatch, while missing/unknown enrollment is permanently manual. A private exact-`None` capability can CAS absence, while any later present/invalid observation irreversibly poisons it to admission-free manual; exact existing send-start recovery atomically adopts the retained candidate as present. The blob also retains exact retry-stable bootstrap/witness bytes, monotonic create admissions, and mutually exclusive normal Tombstoned-witness versus pre-witness absence inventory snapshots/seals. The pre-witness tables bind the full protocol/bootstrap/fence/revision tuple and create-ahead commitment, including a zero-page terminal. On that branch the shared page ledger recomputes the exact deterministic plan for every admission/recovery/reconciliation, accepts only its exact prefix and optional unresolved next page, and rejects every page for the zero-object plan. Only coordinator-private authenticated plans can seal either branch. A separate versioned pre-witness execution row revalidates that exact branch and complete authenticated object set, binds one random operation ID, and full-row-CASes the strict registry/object/drain evidence stages while leaving the lifecycle anchor sealed. A separate inactive maintenance-import family binds one active archive to an opaque operation/owner/session, permanent legacy fence, exact source generation/hash/length/schema/DEK-metadata commitment, exact witness lease, retained R1/parity/R2 evidence, up to 16 immutable attempts, and at most 32,898 exact retained artifact rows per attempt. The dedicated R2 attempt is selected before ShadowWal-bound reconciliation; same-fence empty/reserved/materialized prefixes reopen without burning another attempt, while a full-tuple-validated higher-fence reacquire supersedes a partial attempt and resets its prefix. Renewal/reacquire CAS also matches the exact previous witness bytes, fence, and expiry. Every capability-bearing maintenance mutation uses cancellation-safe owned-handle persistence; no startup or route produces its plan. Separate v1 WAL-owner lease and checkpoint families bind the exact released maintenance terminal, owner identity, full expected/leased witness tuple, and a monotone Prepared/SourceReady/Uploading/CandidateReady/SendStarted/Witnessed/Manual protocol. Checkpoint attempts are capped at 16 and exact-AAD immutable artifacts at 32,898; reserve and every candidate/send/terminal load recompute the full deterministic interleaved chunk/manifest/root topology. The shared lease manager preserves same-fence attempts, supersedes only pre-send work after an authenticated higher-fence reacquire, and never mutates a SendStarted attempt. Unresolved logical publication is mutually exclusive; exact witnessed predecessor publication consumption, checkpoint witness settlement, and owner binding advance are one transaction. Each capability-bearing flush removes the sole SQLite handle from the shared cache until durable conditional PUT or exact lost-response readback; interruption leaves the cache empty so recovery reloads authoritative provider state. Producer-private recovery reconstructs bootstrap and sealed/physical receipts, but no destructive producer or runtime wiring activates the execution protocol. It also holds accounting, protected cost reservations, ADR-0032's bounded user-scoped reference-batch receipts plus their existing per-event delivery authority, webhook destinations/secrets, OAuth clients/codes, refresh tokens, daily usage/Vertex ceilings, and the redacted query log; identity rebind and account deletion migrate or erase the batch rows with their account, and email equality never links providers. |
